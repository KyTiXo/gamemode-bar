Get started

Two minutes, one password prompt.

  1. Install

    curl -fsSL https://kytixo.github.io/gamemode-bar/install.sh | sh

    Beta builds are ad-hoc signed, not notarized. On first launch, right-click the app and choose Open.

  2. Authorize

    Click the controller in your menu bar, then Settings… → Check Permissions…. It checks for full Xcode (the only place Apple ships gamepolicyctl) and installs one sudoers rule that only allows ifconfig awdl0 up and down. No Xcode? No AirDrop still works; only the Game Mode row needs it.

  3. Play

    Choose Enable Game Mode+. Choose it again to put everything back.

When it helps

macOS only turns on Game Mode for apps tagged as games. This turns it on for anything.

AirPlay to a TV

AirDrop's radio (AWDL) hops Wi‑Fi channels in the background. Keeping it off smooths out the stream.

Emulators and streaming

shadPS4, Moonlight, GeForce NOW, and other full-screen play that macOS doesn't treat as games.

Anything on a controller

If you're playing it, it gets Game Mode, whether or not macOS thinks it's a game.

Why not just sudo ifconfig awdl0 down? macOS turns it back on within minutes. Game Mode Bar keeps it down while you play and restores it when you're done. Results vary by Mac, network, and workload. It's a policy toggle, not an FPS patch.

Small on purpose

Nothing to babysit, nothing left behind.

Native AppKit

A standard menu-bar app. No Electron, no background services. Optional run at startup.

Least privilege

One sudoers rule for awdl0 up and down, validated by visudo. Nothing else runs as root.

Reversible

Every change has an off switch, and a failed transition rolls back to where you were.
